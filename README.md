# Short animation film planner
This is the repository for the client side of Short Animation Film Planner application. It's a prototype/predecessor for Kükloop - an application for collecting ideas and references for (animated) films and developing them into a script. The repository for Kükloop is here: https://gitlab.com/MortenTsinakov/kykloop

The prototype was created in collaboration with several independent filmmakers who tested the app and gave valuable feedback.

## Developmen
First, you should start the database and the server (description in back-end repository)

To run the front-end, run the following commands:
```console
npm install
npm run
```

The app should start on ```localhost:3000```.
